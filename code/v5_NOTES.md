# v5 (区間 DP) 理論メモ

v5 の根底にある仮説，現状の経験的根拠，反例，未解決の理論問題のメモ．
深堀り研究のための作業ノート．

## 1. 仮説とその同値表現

### 仮説（経験的）

> ノード `0, 1, ..., N-1` を 1 次元の線上に並べ，ノード 0 を始点とする最適な根付き木を考える．論文の仮定 2.1〜2.3（密度経済，距離経済，極限条件）と `φ > 0, ρ > t > 0` の下では，**ある十分条件のもとで**，最適な根付き木の **すべての部分木が連続区間** をなす．

### 同値表現

**「部分木が連続区間」⟺「平面上で MT リンク同士が交差しない」**

線分上にノードを並べ，各リンクをノード位置を結ぶ円弧として描いたとき，2 本のリンクが「交差」するとは，それらの x 軸上の射影区間が真に挟まる（u₁ < u₂ < v₁ < v₂）こと．

- IT リンク（距離 1）は他のリンクと真に交差不可能．
- 交差し得るのは **MT-MT の組合せのみ**．

### 同値性の証明（直観）

**部分木 = 区間 → 交差なし**：仮に辺 (u₁→v₁), (u₂→v₂) が u₁ < u₂ < v₁ < v₂ で交差するとする．u₁ ∈ subtree(v₁) で区間 [a, v₁] (a ≤ u₁)．u₂ は u₁ と v₁ の間にあるので u₂ ∈ subtree(v₁)．しかし u₂ の親は v₂ ∉ subtree(v₁)．矛盾．

**交差なし → 部分木 = 区間**：反例で確認．非区間部分木をもつ最適解には必ず MT 交差が存在．


## 2. 反例（仮説が破れる場合）

### パラメータ
```
phi = 0.1,  rho = 1.01,  t = 1,  nu = 10,  d = 1,  N = 5
```
- 論文の仮定 2.1, 2.2, 2.3 全てを満たす（検証済み）
- `ρ/t ≈ 1.01`（ほぼ 1），`φ = 0.1`（極めて小）

### 結果
- v2 (厳密 BB) 最適解：`Z = 26.15`，tree = `[-1, 3, 0, 0, 2]`
  - subtree(2) = {2, 4} （非区間）
  - subtree(3) = {1, 3} （非区間）
  - MT-MT 交差：(1→3, 2→0)，(1→3, 4→2)，(3→0, 4→2)
- v5 (区間 DP) の解：`Z = 32.36`（24% 悪い）

### 仮定 2.1, 2.2, 2.3 の検証
全条件成立（per-unit cost `c^MT(x,d) = (φ + ρd)·log(x+1)/x` に対し）：
- Asm 2.1 (x 単調減少): ✓ `∂/∂x [log(x+1)/x] = (x/(x+1) − log(x+1))/x² < 0`
- Asm 2.2 (d 増加 + c/d 減少): ✓
- Asm 2.3 (3 つの極限):
  - `lim_{x→0+} = φ + ρd > t·d` ⇔ `φ > (t-ρ)d`．ρ > t なので φ > 0 で自動成立．
  - `lim_{x→∞} = 0 ∈ [0, t·d)` ✓
  - `lim_{d→0+} = φ·log(x+1)/x ∈ (0, ∞)` ✓


## 3. 未解決問題：仮説が成立するパラメータ範囲の特徴付け

論文掲載 6 ケースは全て `ρ/t ≥ 2.5` かつ `φ ≥ 10`．これらでは仮説成立を実証．
反例は `ρ/t = 1.01`，`φ = 0.1`．境界はその間のどこかにある．

**問**：どんな `(φ, ρ, t, ν, N)` の関係式の下で，すべての（あるいは大域的）最適解で MT 交差が生じないか？

### ノード数 N の影響：ほぼなし（経験的）

ストレスパラメータ (`φ=0.1, ρ=1.01, t=1, ν=10`) で N を変えて v2 vs v5 を比較：

| N | v2 opt_Z | v5 opt_Z | 相対 gap |
|---|---|---|---|
| 5 | 26.15 | 32.36 | +23.76% |
| 6 | 32.45 | 40.46 | +24.68% |
| 7 | 39.73 | 49.30 | +24.07% |
| 8 | 47.06 | 59.18 | +25.74% |
| 9 | 54.94 | 68.33 | +24.39% |
| 10 | 62.90 | 77.72 | +23.57% |
| 12 | 79.51 | 97.51 | +22.63% |

**N=5〜12 のすべてで v5 は失敗（相対 gap ≈ 24%, ほぼ一定）**．N が大きくなっても安全になることはない．

**示唆**：v5 の妥当範囲は本質的に **無次元パラメータ比 `(φ/(t·ν), ρ/t)` の関数**であって，**N の関数ではない**．N は問題のスケールを与えるだけ．

これは妥当：費用関数の構造（IT 線形 vs MT 凹）と「どの組合せで交差が得か」の判断は，局所的な距離・流量比で決まり，問題全体のサイズ N には依存しない．


## 4. 単純な交換議論の限界

最も自然な解析：交差ペア `(u₁→v₁), (u₂→v₂)` を `(u₁→v₂), (u₂→v₁)` にスワップしたときの ΔZ．

**主要 2 辺の差分**（u₁ < u₂ < v₁ < v₂ のとき）：

```
ΔZ_main = ρd (v₂ - v₁) log((f₁ + 1) / (f₂ + 1))
```
ここで `f_i = ν · |subtree(u_i)|`．

- f₁ < f₂：ΔZ_main < 0（交換が改善）
- f₁ > f₂：ΔZ_main > 0（交換が改悪）
- f₁ = f₂：ΔZ_main = 0

ところが**スワップは v₁, v₂ より上流の辺の流量も変える**：v₁ の上流に乗っていた f₁ が消えて f₂ が乗る．v₂ 側はその逆．凹費用 log で上流効果が累積．

- f₁ = f₂ のとき（subtree サイズが同じ）：主要 2 辺 ΔZ_main = 0 かつ上流効果も 0．**スワップは無差別**（同コストの非交差解が存在するだけで，交差解を排除できない）．
- f₁ ≠ f₂ のとき：主要効果と上流効果が打ち消し合うため，符号が一意に定まらない．

つまり **「単純な 2 辺スワップ」では交差が必ず排除されることを示せない**．

さらに IT/MT 境界の不連続性（距離が 1 になると線形）もあって解析を難しくする．


## 5. アプローチ案

### A. 経験的マッピング（最も実装しやすい）

`(φ, ρ, t)` の 2 次元グリッドで v5 と v2 を比較し，**仮説が成立する領域を heatmap として可視化**する．

- `t = 1` 固定
- `φ ∈ [0.01, 100]`（log scale），`ρ/t ∈ [1.01, 50]`（log scale）
- 各点で `N=8` くらいの小規模ケースを解いて opt_Z 一致を確認
- 一致：緑，不一致：赤の色塗り

得られるもの：実用上の安全範囲の境界が経験的に見える．**論文の数値実験 (ρ/t ≥ 2.5, φ ≥ 10) が安全領域に余裕で入っている**ことを示せる．

### B. 単純交換による十分条件（loose な理論）

2 辺スワップ + 上流 k 段の効果を合わせた ΔZ を解析し，「すべての交差ペアで ΔZ ≥ 0 なら大域最適は交差なし」を示す．

得られるもの：`φ ≥ g(ρ, t, ν, N)` 形の **十分条件**（実態より厳しめだが厳密）．


### C. 厳密な必要十分条件（研究レベル）

全ての交差形態と全ての非交差代替案を考慮し，パラメータの関係式として特徴付ける．未解決と思われる．

得られれば論文 1 本に値する．

## 7. 実装メモ

### v5 の計算量
- 状態：`f(a, b, r)` で O(N³)，`M(a, c, p)` で O(N³)
- 遷移：`M` の inner DP に O(N²)
- 合計：O(N⁵)，メモリ O(N³)

### 高速化の余地
- 補助配列 `G[i, j, p] = min_r f[i, j, r] + link(r, p, ν(j-i+1))` を先に計算すれば O(N⁴) に改善可能（メモリも O(N³) のまま）．
- N=100 程度なら O(N⁵) でも数百 ms で許容．より大きい N でやる場合は O(N⁴) 化が必要．
